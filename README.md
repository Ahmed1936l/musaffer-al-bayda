# مسافر البيضاء | Musaffer Al Bayda

موقع عربي ثابت لنشاط **وساطة وتنسيق حجوزات مقاعد الرحلات** بين المسافرين والسائقين، من محافظة البيضاء إلى المملكة العربية السعودية بحسب الرحلات المتاحة فعليًا.

> الموقع لا ينفذ حجزًا أو دفعًا آليًا، ولا يعني إرسال الاستفسار تأكيد الحجز. يتم تأكيد التفاصيل بالتواصل المباشر وبعد الاتفاق.

## هيكل الملفات

- `index.html` — الصفحة الرئيسية.
- `services.html` — الخدمات.
- `destinations.html` — الوجهات القابلة للتنسيق عند التوفر.
- `booking.html` — خطوات الاستفسار وتأكيد المقعد.
- `contact.html` — الهاتف ومعلومات التواصل.
- `css/style.css` — الهوية البصرية والتصميم المتجاوب.
- `js/main.js` — قائمة الهاتف وتحديث السنة.
- `assets/favicon.svg` — أيقونة الموقع.
- `robots.txt` و`sitemap.xml` — أساسيات SEO.
- `404.html` — صفحة الخطأ.

## تعديل النصوص

افتح الصفحة المطلوبة وعدّل النص العربي داخل عناصر HTML مع الحفاظ على العناوين `h1` و`h2` لتبقى بنية الصفحة واضحة لمحركات البحث.

## تحديث الوجهات

عدّل بطاقات الوجهات في `destinations.html`. أبقِ عبارة **رهن التوفر والتأكيد** ما لم يؤكد صاحب النشاط أن وجهة معينة متاحة فعلًا. لا تضف أسعارًا أو مواعيد ثابتة من دون مصدر مؤكد.

## تعديل رقم الهاتف

عدّل الرقم الظاهر ورابط `tel:` في `contact.html`. الرقم الحالي مكتوب بصيغة محلية `0730561649`، ورابط الاتصال يستخدم الصيغة الدولية المتوقعة `+967730561649`. يجب تأكيد ملكية الرقم وصحة الصيغة مع صاحب النشاط قبل تعديل روابط واتساب أو نشرها.

## تحديث رابط واتساب

لا يوجد رابط واتساب منشور في النسخة الحالية لأن توفر الرقم على واتساب لم يُؤكد. بعد التأكد، يمكن إضافة رابط من النمط:

`https://wa.me/967730561649?text=...`

مع ترميز الرسالة في الرابط، وإبقاء الرسالة قابلة للتعديل وعدم اعتبار إرسالها تأكيدًا للحجز.

## النشر على GitHub Pages

1. ادفع التعديلات إلى فرع `main`.
2. من إعدادات المستودع اختر **Pages**.
3. اختر النشر من فرع `main` ومن مجلد `/ (root)`.
4. انتظر اكتمال عملية النشر.
5. اختبر الصفحة الرئيسية والصفحات الداخلية وملفات CSS وJavaScript.

هذا المشروع لا يحتاج إلى عملية بناء أو تبعيات خارجية؛ لذلك يعمل مباشرة على GitHub Pages.

## ربط نطاق خاص مستقبلًا

من إعدادات GitHub Pages أضف النطاق المخصص، ثم أنشئ سجلات DNS المطلوبة لدى مزود النطاق. بعد ذلك أضف ملف `CNAME` في جذر المشروع إذا طلب GitHub ذلك، وحدّث عناوين `sitemap.xml` و`robots.txt` إلى النطاق الجديد.
